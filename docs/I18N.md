# 다국어

`src/i18n`: ko · en · ja. 대체 순서는 지금 언어 → en → ko.

```ts
configureI18n({ storageKey: 'my-game.lang', defaultLang: 'ko', languages: ['ko', 'en'] });
registerStrings({ 'hud.hint': { ko: '땅을 클릭하세요', en: 'Click the ground' } });
t('hud.hint');                               // 지금 언어
t('hud.time', { n: 3 });                     // {n} 자리표시
onLangChange(() => render());                // 언어가 바뀌면 다시 그린다
```

- **UI 문자열**: `registerStrings({ 'area.name': { ko, en, ja } })`, `t(key, vars)`. DOM은 `[data-i18n="키"]` + `localize(root)`.
- **대사**: `{ speaker, text: '한국어', en, ja }` 객체를 `*.lines.ts`에 둔다. `lineText(line)`이 지금 언어 문장을 준다.
- **원문 카탈로그**: 게임 스크립트가 한국어 원문을 그대로 넘기는 화면 문구는 `registerCatalog({ '남은 시간 {0}초': { en: '{0}s left', ja: '残り{0}秒' } })`, 표시하는 쪽이 `tx(ko)`.
- **언어 고르기**: 저장된 언어가 없으면(`!languageChosen()`) 첫 화면 앞에 `new LanguageSelect(uiContainer()).choose()`. 설정 메뉴(`SettingsMenu`)에도 언어 줄이 있다. `?lang=en`은 저장하지 않고 이번 세션만 바꾼다.
- **일본어 글꼴·줄바꿈**: `i18n.css`가 `:lang(ja)`에서 일본어 글꼴 목록(`--ui-ja`)과 `line-break: strict`, `word-break: auto-phrase`를 쓴다.

## 도구

- `npm run lines` → http://127.0.0.1:5180/ : `*.lines.ts`의 대사(한·영·일)를 브라우저에서 고쳐 파일에 바로 쓴다. 설정은 `lines.config.json`(`src`, `speakers`, `docs`, `order`, `port`). `docs` 폴더(*.md 대본)에 같은 문장이 한 번만 있으면 대본도 같이 고친다.
- `npm run i18n:check` : 대사 파일별 en·ja 수, 화면 문구(한글 문자열 리터럴)의 카탈로그 적용률. `--missing`, `--dump <file>`, `--screen <path>`.
- `npm run i18n:fill -- <lines.ts> <translations.json>` : 번역 JSON으로 대사 파일에 en·ja를 채운다.
- 경로는 `i18n.config.json`(`src`, `lines`, `catalog`, `skip`, `skipFiles`, `ignoreFile`).
